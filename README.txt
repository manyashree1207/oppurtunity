Opportunity Hunter interactive demo

Files:
- index.html: self-contained interactive frontend prototype.
- DEMO_SCRIPT.txt: hackathon presentation script.

Run:
1. Extract the ZIP.
2. Open index.html in Chrome or Edge.
3. Change the filters and click Search opportunities.
4. All cards are illustrative sample data. TinyFish is not connected.

This frontend demo does not call an API or send user data anywhere.
